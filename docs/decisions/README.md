# Product, Policy and Governance Decisions

Use this folder for product rules and governance choices that are not primarily technical architecture decisions: voting eligibility, scoring policy, evidence labels, correction rights, role powers, privacy principles, content moderation and transparency. Suggested filename: `DEC-NNN-short-title.md`.

Each record must include: title, date, status, decision owner, context, options, decision, rationale, user impact, risks, affected requirements and review date. Status values: PROPOSED, ACCEPTED, REJECTED, SUPERSEDED. Only the human project owner may accept a decision. Preserve history by superseding, not deleting.
